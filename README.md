# lnrd.mrl — Portfolio

Portfólio minimalista bilíngue para GitHub Pages, sem dependências externas.

## Publicação

1. Crie um repositório público `oleoamaral.github.io`.
2. Envie `index.html`, `styles.css` e `script.js` para a raiz do repositório (não envie a pasta que os contém).
3. Em **Settings → Pages**, selecione **Deploy from a branch**, `main` e `/ (root)`.
4. Acesse `https://oleoamaral.github.io` após o deploy.

## Edição

- `index.html`: estrutura, projetos e links.
- `styles.css`: cores, tipografia, espaçamento e layout.
- `script.js`: traduções PT/EN.
- A assinatura `lnrd.mrl` foi reproduzida em texto com fonte serifada de fallback, **não** como cópia exata da fonte Rockwell mostrada na referência.
- As quatro categorias de projetos são **placeholders**, não afirmações de projetos concluídos.
- Para conteúdo profissional sob NDA, publique apenas informações autorizadas. Não coloque documentos confidenciais no repositório nem no histórico Git.

## Assinatura vetorial
A marca `lnrd.mrl` está em `assets/lnrd-mrl.svg`, com letras convertidas em curvas e ponto azul. Não depende de fontes instaladas no dispositivo. É uma aproximação tipográfica inspirada na referência, não uma reprodução exata da fonte Rockwell.
